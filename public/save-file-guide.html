How to install a GTA San Andreas save on PC

Use these steps for the original Windows release. The verified 100% save is named GTASAsf1.b and appears in Slot 1.

Download the 100% save ↓Open save editor ↗

Where is the save folder?

In File Explorer, open Documents → GTA San Andreas User Files. This is your Documents folder, separate from the game installation. If you can’t find it, save once in the game and search for GTASAsf1.b or the slot you used.

Install the downloaded save

  1. Close GTA San Andreas. Copy your current save files to a backup folder.
  2. Copy the downloaded GTASAsf1.b into GTA San Andreas User Files. To use a spare slot, change the final digit to an unused slot from 1 through 8.
  3. Start the game and choose Load Game. Select the slot containing “End Of The Line.”

Which versions are supported?

The editor supports the classic Windows PC save layout (202,752 bytes). Mobile, console, and Definitive Edition saves use other formats. Named mission fields require standard PC v1 or v2 scripts. Test exports in a spare slot, especially if your installation changes the main script.

How do I edit and export a save?

Open the editor and choose your .b file. After editing, select an output slot in Overview and click Download edited save. The editor updates the checksum; your original remains unchanged. Changing a mission counter does not run rewards or recreate the conditions for replaying a mission.

How do I enable CJ’s 3D preview?

Open your .b save, then click Clothes & 3D model or Dressing room. CJ’s model appears automatically. Choose an item to see it on CJ and apply it to your loaded save. The save stays in your browser.

How to play the original San Andreas radio

Open the radio on the homepage, select an icon in the station grid, and press Play if your browser blocks automatic playback. Use the station arrows to tune in, or the track arrows to skip. Choose Radio Off for silence.

The radio starts at 10% volume where supported. It plays original PC songs and talk segments as a playlist. It doesn’t recreate the game’s DJ scheduling or advertisements.
